# Aarti Library Website Clone

A modern, responsive clone of the Aarti Library & Study Center website.

## Features

- **Fully Responsive Design** - Works seamlessly on desktop, tablet, and mobile devices
- **Modern UI/UX** - Beautiful gradient hero section with smooth animations
- **Interactive Components**:
  - Sticky navigation with active link highlighting
  - Hamburger menu for mobile devices
  - Auto-rotating testimonials slider
  - Animated gallery with hover effects
  - Interactive contact form
  - Smooth scrolling navigation

## Sections Included

1. **Home/Hero** - Eye-catching hero section with call-to-action buttons
2. **About Us** - Information about the library with feature highlights
3. **Features** - Detailed features grid showcasing library amenities
4. **Gallery** - Image gallery with hover effects
5. **Media Coverage** - Media recognition section
6. **Testimonials** - Auto-rotating testimonial slider
7. **Contact** - Contact information and form
8. **Footer** - Copyright and credits

## Technologies Used

- HTML5
- CSS3 (Flexbox & Grid)
- Vanilla JavaScript
- Font Awesome Icons
- Google Fonts

## How to Run

Simply open the `index.html` file in any modern web browser:

1. Navigate to the project folder
2. Double-click `index.html` or right-click and select "Open with Browser"
3. The website will load and be fully functional
